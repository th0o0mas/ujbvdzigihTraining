Administration — utilisateurs

Cette page fabrique l’entrée d’un utilisateur pour js/users.js : le jeton GitHub est chiffré dans votre navigateur avec le mot de passe choisi. Rien n’est envoyé ailleurs, sauf la vérification facultative du jeton auprès de GitHub.

Pour changer un mot de passe, refaites simplement l’opération avec le même identifiant et remplacez l’ancienne ligne.

Ligne à coller dans js/users.js

Collez-la entre les accolades de export const USERS = { … };, enregistrez, puis envoyez la mise à jour sur GitHub.
